Como é garantido que os atendimentos NUNCA se misturam?

Nossa arquitetura foi desenhada com isolamento estrito em 3 camadas:

1. Banco de Dados

No Chatwoot, cada operação é uma Account (Tenant) distinta. Todas as tabelas são filtradas por account_id no PostgreSQL.

2. Sessão WhatsApp

Na Evolution API, cada número roda como um processo isolado com sua própria pasta de tokens e chaves criptográficas.

3. Webhooks Dedicados

Quando um atendente envia uma mensagem, o webhook é roteado especificamente para a instância daquela operação.
